# Portfolio Website

A modern responsive portfolio website built using React.js and Tailwind CSS to showcase my skills, projects, and experience as a MERN Stack Developer.




---

## 📌 Project Overview

This portfolio website is designed to present my personal and professional work in a clean, responsive, and user-friendly interface. It includes:

- Hero section with introduction
- About me section
- Skills showcase
- Projects portfolio
- Contact information

The goal is to provide recruiters and clients a quick overview of my technical abilities and projects.
